# Contributing to reactifyui-icons

Thank you for your interest in contributing to **reactifyui-icons** 🎉  
We welcome contributions that improve the quality, consistency, and usability of the library.

This document explains **how to contribute correctly**, whether you’re adding icons, improving tooling, fixing bugs, or enhancing documentation.

---

## 🧭 Project Philosophy

reactifyui-icons is built as a **UI-system icon foundation**, not a decorative icon pack.

### Core principles:
- Fill-only icons (no stroke)
- `currentColor`-based styling
- Predictable behavior in real UI systems
- Tree-shakable, lightweight exports
- Accessibility-first
- Strong validation & testing

All contributions must align with these principles.
